# Room status: built vs described

Every room the catalog (ROOMS.md) describes, and whether it's in the game (`data/rooms.json`). Generated by `node scripts/room-status.mjs`; rerun it after adding rooms. What an unbuilt room needs first is kept by hand in the script.

**At a glance:** 58 room types built. Of the 91 rooms in the catalog's tables, 51 are built and 40 are described only. Of those, 4 need nothing new (A), 5 need one new resource, effect or unlock (B), and 30 need a new system (C).

**Needs, graded:** **A** uses what the game already has (resources, effects, rules). **B** needs one new resource, effect type or unlock. **C** needs a whole new system (goods, tourism, safety, commutes, H-size rooms…).
